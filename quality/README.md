# Локальный контроль качества MailRu Desktop

Первый профиль состоит из сборки приложения и библиотеки Protocol,
синтетических проверок InteractionLogicSmoke и анализа зависимостей .NET.
Реальная отправка писем, доставка push, установка и приёмка не запускаются.

Команда:
`python scripts/quality_runner.py --profile full`

Проверка истории полученных push-событий изолирована: тестовые экземпляры
`MailRuPushBackgroundService` используют инъецированный in-memory обработчик,
а не реальное зашифрованное хранилище аккаунтов в профиле пользователя.
Повторные прогоны не зависят от событий прошлых тестов.

Отчёт: `quality/reports/quality-full-*.json`.
Карта: `quality/reports/architecture.html`.
