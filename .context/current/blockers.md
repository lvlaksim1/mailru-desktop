# Открытые проблемы и технические долги — v0.3.30 (2026-10-09)

1. **Приёмка отображения писем.** Мерцание тела, медленное открытие некоторых HTML-писем и два встроенных GIF из чека Магнита оставались дефектами v0.3.29. v0.3.30 меняет архитектуру показа: DOMContentLoaded вместо ожидания изображений, параллельные WebView2 ресурсы с OAuth для afNN.mail.ru, отмена старых запросов. Полноценный успех на авторизованной сессии владельца НЕ подтверждён. Сохранять безопасные категории диагностики mail_image_inline и mail_render_timing без приватных данных.
2. **Сохранение и загрузка Markdown.** Новая папка по умолчанию и Save As реализованы, но владелец ещё не подтвердил в установленном v0.3.30, что начальная папка именно Templates, сохранение под новым именем не трогает исходный .md, совпадающее имя требует подтверждения, вложения копируются. Автономные тесты пройдены.
3. **Отправить сейчас для уже отложенных писем (#77) — ЗАБЛОКИРОВАНО.** Нет протокольных и сквозных доказательств атомарной отмены исходной плановой отправки. Нельзя повторно отправлять то же письмо новым вызовом обычного send: риск дубликата. План в docs/protocol/scheduled-send-now-safety.md. Кнопки не включены в v0.3.30.
4. **Точная доставка по расписанию и подтверждения прочтения** ещё не подтверждены полным циклом с контролируемым получателем.
5. **Новые серверные маршруты поиска** требуют доказательств. Ранее go.mail.ru возвращал HTTP 520; не переключать рабочую логику без проверенного ответа.
6. **Неприкосновенность принятых функций.** Владелец сообщает, что остальные изменения v0.3.29 выглядят нормально. Сохранять аккаунты, перетаскивание, фотографии отправителей, контакты, темы, обновления и подтверждённую изоляцию авторизации. Поиск фотографий отправителей закрыт.
7. **Безопасность.** Запрет IMAP/SMTP и паролей приложений, запрет публикации токенов и содержимого писем; исследовательские сетевые запросы с паузой ≥5 секунд. Для тестирования доставки использовать исключительно разрешённую тестовую переписку.
