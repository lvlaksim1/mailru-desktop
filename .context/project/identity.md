# Project identity

- **Name:** MailRu Desktop
- **Repository:** `lvlaksim1/mailru-desktop`
- **Role:** product repository
- **Purpose:** a standalone native desktop Mail.ru client implemented from scratch against reverse-engineered internal Mail.ru APIs.
- **Primary platform:** Windows desktop.
- **Protocol focus:** current and evolving internal Mail.ru HTTP APIs, with `aj-https.mail.ru` as the initially verified host family.

This repository owns both the application and the project-local reverse API specification.
