# Шаблоны писем MailRu Desktop

Папка: `%LOCALAPPDATA%\MailRuDesktop\Templates`.

**Каждый файл `Название.md` — отдельный шаблон.** Название шаблона берётся из имени файла, а не из его содержимого. Добавить шаблон можно прямо из программы или вручную, скопировав `.md` в эту папку. В редакторе настроек есть кнопка **«Открыть папку шаблонов»**. При изменениях папки перечитывается список файлов; он также обновляется при открытии настроек и раскрытии списка шаблонов в ответе.

## Самый простой файл

Файл `Приветствие.md`:

```markdown
Здравствуйте!

Спасибо за ваше письмо.
```

Это шаблон с телом письма без заданной темы или вложений.

## Тема и вложения

Файл `Ответ клиенту.md`:

```markdown
---
subject: "Ответ на ваше обращение"
attachments:
  - "_attachments/Ответ клиенту/прайс.pdf"
---

Здравствуйте!

Благодарим за обращение.
```

Верхняя часть между строками `---` — необязательные сведения. Для значений желательно использовать JSON-строки в кавычках (так надёжно сохраняются кавычки, обратные косые черты и необычные символы). Текст после второго `---` — тело письма в формате Markdown.

Пути к вложениям могут быть относительными к папке `Templates` или абсолютными. При сохранении из интерфейса программа копирует новые вложения в `Templates\_attachments\Название шаблона` и записывает в файл относительные пути. Если файл вручную указан, но отсутствует, шаблон всё равно показывается; при вставке отсутствующие вложения пропускаются с сообщением.

## Поведение

- Создание и редактирование в настройках записывает соответствующий `.md`.
- Переименование меняет имя `.md`, сохраняя его содержимое.
- Удаление удаляет только файл `.md`; вложения автоматически не удаляются, поскольку на них могут ссылаться другие шаблоны.
- Вставка шаблона в ответ **без подтверждения** заменяет тему, тело и список вложений.
- При первом запуске новой версии прежние шаблоны из `settings.json` переносятся в файлы `.md`. Старые данные не удаляются и остаются запасной копией.

## Аватары

Компактные изображения контактов и аккаунтов запрашиваются через службу Mail.ru `https://filin.mail.ru/pic?email=...`, обнаруженную в ресурсах официального клиента. Если адрес пуст, изображение недоступно или не распознаётся средствами Windows, остаются инициалы. Размер визуального элемента — 16 × 16 пикселей; высота строки не меняется. Поведение службы и изображения следует отдельно проверить в установленной программе.
