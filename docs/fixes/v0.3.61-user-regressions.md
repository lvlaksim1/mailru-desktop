# MailRu Desktop v0.3.61 — пользовательские замечания после этапа 1

Источник: скриншоты и K-003.mp4, предоставленные владельцем 13.10.2026. Версия продукта до изменений: v0.3.60.

## Наблюдения

1. Некоторые фотографии и значки отправителей не отображаются. Для элементов без успешно загруженной фотографии видно резервное обозначение отправителя. Наличие подходящих URL и сетевой ответ по каждому проблемному отправителю этим видео не установлены.
2. На записи K-003.mp4 при движении разделителя в главной почте содержимое длинных строк выходит за выделенную панель, появляются лишние горизонтальные области. Источники: собственные минимумы колонок современного шаблона и отсутствие ограничения содержимого видимыми пределами панели.
3. На скриншоте формы ответа правильные русские слова подчёркиваются проверкой. Редактор WPF RichTextBox не назначал язык и наследовал en-US.

## Исправления

- Для редакторов RichComposeEditor при регистрации включаем `Language=ru-RU` до запуска штатного `SpellCheck`. Это устраняет неверное применение английского языка ко всему русскому письму. Работа зависит от доступных системных словарей Windows; полноценное автоматическое определение языка слов отдельно не добавлялось.
- В MainWindow.xaml ограничиваем отображение MailWorkspace и списка `ClipToBounds`, отключаем горизонтальное смещение внутри MessagesGrid. Список не рисуется поверх области просмотра при изменении ширины. Отдельные пользовательские размеры колонок сохраняем без перерасчёта и не меняем состав действующего шаблона. Если панель слишком узкая, часть колонок визуально обрезается вместо выхода за границу; скрытые поля видны при расширении панели.
- AvatarImageBehavior повторяет неуспешную загрузку только ограниченное число раз для ещё видимых изображений, сохраняет проверку HTTPS и разрешённых доменов, защищает от устаревшего результата при повторном использовании строки. Этот механизм исправляет временные сбои, но **не гарантирует появление отсутствующих URL или картинок, которых нет на сервере**. При постоянном отсутствии нужны обезличенные сообщения `avatar_image` из диагностики (без URL, адресов, токенов).

## Приёмка

Автономные Windows CI — сборка приложения, проверка интерфейса, сохранение параметров, каталог элементов и проверка запуска. На ПК владельца: проверить указанные отправители, перемещать центральный разделитель до узкой панели, развернуть обратно и сверить сохранение размеров, в форме ответа набрать несколько правильных русских слов и намеренную ошибку. Если проверка русского языка всё равно работает неправильно, проверить наличие словаря русского языка в Windows и обдумать самостоятельный словарь в следующем отдельном изменении.

Mail.ru HTTP, Google/MCS, PushMe, письма, хранилища, семантика выделения и этап 2 рефакторинга не менялись.
