# Разбор Mail.ru Android 15.107.0.148045

Исследуемый пакет: `ru.mail.mailapp` 15.107.0.148045.

Исходный комплект сохранён в этой исследовательской ветке частями и может быть восстановлен с проверкой SHA-256.

## Что уже сделано

- основной APK и split APK сохранены в `package/`;
- основной APK содержит 21 DEX;
- выполнена декомпиляция JADX 1.5.6;
- сохранены сетевые и почтовые классы текущего официального Android-клиента;
- восстановлены точные почтовые маршруты из `@UrlPath`;
- восстановлены основные GET/POST-параметры и структуры тел запросов;
- извлечены значения серверных ресурсов из `resources.arsc`;
- сформирована человекочитаемая и машинная карта договоров запросов;
- сформирована матрица готовности функций к переносу в Mail.ru Desktop.

## Главные документы

- `AJ_API_SPEC.md` — сводная спецификация почтового протокола с разделением доказательств APK и живого AJ;
- `APK_ROUTE_MAP.md` — точная карта методов и маршрутов текущего APK;
- `APK_REQUEST_CONTRACTS.md` — автоматически извлечённые параметры и ключи ответов;
- `APK_REQUEST_CONTRACTS.json` — та же карта в машинном виде;
- `APK_HOST_RESOURCES.md` — серверные адреса из таблицы ресурсов APK;
- `IMPLEMENTATION_MATRIX.md` — готовность функций к реализации в Mail.ru Desktop;
- `decompiled/` — сохранённые декомпилированные сетевые классы;
- `tools/extract_contracts.py` — воспроизводимый извлекатель договоров запросов.

## Ключевые выводы

Почтовый сетевой слой текущего Android-клиента использует семейство Tornado и строит адреса из сегментов маршрута. Слой сеанса добавляет `access_token`; общие параметры содержат `lang`, а почтовые команды — `email`.

Восстановлены операции загрузки писем и цепочек, полного письма, отметок, перемещения, удаления, спама, папок, поиска, отправки, черновиков, отложенной отправки, вложений, адресной книги, фильтров, отписки, категорий, EML, метаданных, подтверждения прочтения и умных ответов.

Новый механизм поиска `/api/v1/go/search/emails` использует отдельный узел `go.mail.ru`. При принятом правиле проекта «почтовые операции только через aj-https.mail.ru» он исключён; для Mail.ru Desktop остаётся AJ-поиск `/api/v1/messages/search`.

Отдельный AJ-маршрут серверной отмены уже отправленного письма в текущем APK не найден. Пользовательская отмена в Android-клиенте реализована локальной задержкой до выполнения запроса отправки.
